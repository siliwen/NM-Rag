## 为什么扫描件是"造的"

网上的非遗 PDF 绝大多数带文本层，直接拿去测，走的全是文本层分支——**OCR 那半条路一次都没被执行过**，
"测试通过"是假的。所以用 `code/scripts/make_scan_sample.py` 把真实的政府文件页面栅格化成
纯图像 PDF（加了轻微倾斜与噪点），强行制造"没有文本层"的条件：

```bash
cd code
.venv\Scripts\python.exe scripts/make_scan_sample.py \
  "../assets/samples/pdf/十四五非物质文化遗产保护规划.pdf" \
  --pages 1-2 --out "../assets/samples/pdf/模拟扫描件-非遗规划-p1-2.pdf" \
  --noise 5 --rotate 0.5
```

脚本末尾会自检输出文件的文本层字符数，必须为 0 才算成功（否则它就不是扫描件，测了个寂寞）。

拿到真实的传承人申报书扫描件后，请直接放进本目录并更新上表——真实扫描件通常有装订阴影、
纸张泛黄、印章遮挡，识别难度明显高于合成样本。
